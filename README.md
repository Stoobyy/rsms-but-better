# rsms but better

A Chrome extension that replaces the RSET student portal (RSMS) with a cleaner UI. Same data,
same login, no backend — it runs on the portal's own pages and reads them for you.

Sign in with just your UID (the part before `@rajagiri.edu.in`).

## Install

1. Download this folder (or clone the repo).
2. Open `chrome://extensions` in Chrome.
3. Turn on **Developer mode** (top right).
4. Click **Load unpacked** and select the folder.
5. Go to <https://www.rajagiritech.ac.in/stud/ktu/Student/Home.asp>.

To see the original portal, click the extension's toolbar icon (toggles it off) or use the
**Original portal** link at the bottom of the sidebar.
